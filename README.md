## ⚙️ Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/senbame/Machine-Learning.git
cd Machine-Learning

# 2. Create a virtual environment
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate

# 3. Install the dependencies of the project you need
pip install -r requirements.txt
```

> ℹ️ See the README inside each project for detailed setup instructions.
