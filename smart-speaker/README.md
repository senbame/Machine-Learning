# Smart Speaker
Этот репозиторий объединяет три отдельных проекта для локального голосового ассистента:

1. ASR-eval для сравнения моделей Whisper разных размеров.
2. Intent-classifier для распознавания интентов пользователя.
3. Assistant для сборки ASR + NLU + действий + TTS в единый локальный ассистент.

## Порядок работы
1. Сначала оценить и выбрать модель ASR в проекте `asr-eval`.
2. Затем обучить и проверить классификатор интентов в `intent-classifier`.
3. После этого собрать локального ассистента в `assistant`.
